# Purge Focus — 基于 Purge Community 1.6.86 核心模块的精简派生版

**这次不是仅有提示词。**保留原版 `lib/index.js` 中的 DSH `llm/stream` 钩子，采用原版 `lib/refusal-retry.js` 的“检测答复开头 → 限定一次重试”机制，并修改过于宽泛的拒答判定。提示词段只负责口吻；流钩子负责运行时重试。

上游仓库：https://github.com/kingcharleslzy-ai/dsh-purge ，上游固定版本 v1.6.86（树 SHA `126caa2c99297223a7e0e87e604aecfc802f396e`）。本项目只抽取及重构**与当前需求相关的两个核心模块**，不是原仓库完整源码的“原地修改”或原作者发行版。

## 保留的运行时机制

- 使用原版 DSH `ctx.on('llm/stream')` 机制，在模型输出第一段时检测典型误拒答。
- 若命中且含系统消息，则**最多重试一次**。二次回答无论如何原样返回，防止循环消耗。
- 不动用户原始消息；仅第二次请求附加“复核是否将普通请求误分类”的说明。
- 一旦发现工具调用、思考流或取消请求，不做重试；不记录聊天正文或凭据。
- 独立的、可关闭的普通答复风格 section。

## 明确移除

全部宿主补丁（原版的 86 条）、沙箱/审批/文件权限绕过、身份重写、hooks-deny、redteam、unrestricted 预设、越权指令、无限拒答重试、自动更新、自动脚本执行、外部连接、隐藏控制台、OAuth 修改、自动执行工具。

## 安装与测试

在**未启用其他 Purge 版本**的 DSH 环境中，使用 DSH 自带的插件管理器安装本地 `.tgz`。CLI 的示例（仅当正在使用 `web` profile，且有 `dsh` 命令时）：

```sh
dsh plugin --profile web add ./dsh-purge-focus-1.6.86-focus.1.tgz
```

请在 DSH 的插件页面验证它被加载，并用无害的成人关系话题测试答复。测试之前建议先关闭原版 Purge，避免重复 `llm/stream` 钩子。不要在同一运行实例内同时加载两者。

本包只在 Node.js 22 上完成单元测试，**未在 DSHGO / 实际 DSH Desktop 实机进行验证**。它无法改变云端模型的固有政策，不能保证消除所有拒答，更不能保证账户绝对无风险。
